Free learning material for IBB/Viona students in the ITT-Net-Lin module.

This project introduces PowerShell basics and shows how to manage Hyper-V virtual
machines with PowerShell commands and scripts.

##  1. <a name='Gettingstarted'></a>Getting started

Start with the PowerShell basics, then continue with the Hyper-V guides and examples.

##  2. <a name='Requirements'></a>Requirements

- Windows with Hyper-V enabled
- PowerShell

Some commands can change or delete virtual machines and files. Review commands
carefully before running them.

##  3. <a name='Openforcontributing'></a>Open for contributing

Contributions are welcome. Feel free to suggest improvements, report issues, or
submit examples that help students learn PowerShell and Hyper-V.
